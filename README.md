# Multi-Theme Switcher App

This is a ReactJS application built using **TypeScript**, **styled-components**, and **Context API**, supporting three dynamic themes with persistent selection.

## 🚀 Features

- 🎨 Three distinct themes with unique layout, font, and colors
- 🌙 Dark mode and colorful theme support
- 🔁 Theme selection persists across reloads via localStorage
- 📦 Product list fetched from [Fake Store API](https://fakestoreapi.com/products)
- 📱 Fully responsive layout for mobile and desktop
- 🔀 React Router with Home, About, and Contact pages
- 💡 Subtle animations when switching themes
- 🔒 Minimal secure setup, no direct exposure of credentials

## 🛠️ Tech Stack

- React + TypeScript
- Styled-Components
- Context API
- React Router
- Fake Store API

## 📦 Setup Instructions

1. **Clone the repository**
```bash
git clone https://github.com/iShahzaib/Mohd_Shahzaib_Hussain_ReactJS_Developer.git
cd Mohd_Shahzaib_Hussain_ReactJS_Developer/multi-theme-switcher-app
```

2. **Install dependencies**
```bash
npm install
```

3. **Start the development server**
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

> ⚠️ Ensure Node.js is installed on your machine before running the project.
